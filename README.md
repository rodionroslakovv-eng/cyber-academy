# Кибер-академия

Учебная платформа: от нуля до уровня middle в кибербезопасности. Выбираешь направление (Азы / Синяя сторона / Красная сторона), проходишь короткие капсулы: теория → практика → проверка от ИИ-наставника.

## Запуск

Нужен только Python 3 (или любой статический сервер).

- Windows: двойной клик по `start.bat`, затем открой http://localhost:8000
- Вручную: `python -m http.server 8000`

Сборка не требуется: это один файл `index.html`.

## ИИ-наставник (Gemini)

1. Получи ключ в Google AI Studio.
2. В приложении нажми «⚙ ИИ», вставь ключ и сохрани.

Ключ хранится только в браузере (localStorage) и не попадает в репозиторий. Не вставляй его в код.

## Структура

- `index.html`: всё приложение (каркас, капсулы, терминал-симулятор, проверка ИИ)
- `start.bat`: локальный сервер для Windows
